# 12V Fan Testing Jig - Automated Bulk Testing

Individual Project @ MAS Innovations

## Problem
Manual testing of 12V air-cooler fans was time-consuming and inefficient for bulk production testing.

## Solution
Developed an automated testing jig to test fans faster and accurately with automatic data logging.

## Features
- **IR RPM Sensor** - Measures fan speed accurately
- **INA3221 Current Sensing** - Monitors current draw for fault detection
- **QR Code Identification** - Each fan tracked by QR
- **Nextion Display** - Real-time test status for operator
- **AWS Dashboard Integration** - Automatic test data upload & centralized monitoring

## Tech Stack
ESP32, INA3221, IR Sensor, Nextion Display, AWS IoT, C++, PCB Design

## Result
Enabled faster, accurate bulk testing with automatic test data uploading and centralized monitoring. Reduced manual testing time significantly.
